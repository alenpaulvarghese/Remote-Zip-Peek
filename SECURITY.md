# Security

Lazy ZIP handles untrusted archives from untrusted servers, so security reports are very welcome.

## Reporting a vulnerability

Please use **Report a vulnerability** on the repository's [Security tab](https://github.com/alenpaulvarghese/Remote-Zip-Peek/security) rather than opening a public issue. Include the steps to reproduce it, and a sample archive or server behavior if you can.

## What's in scope

- Writing files outside the folder the user chose
- Crashing or exhausting memory or disk with an archive or a server response
- Running code through the app's webview
- Exposing signed URLs or other secrets

## Supported versions

Only the latest release gets security fixes.
